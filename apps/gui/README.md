# AJ199 Control (Tauri)

Графический конфигуратор AJAZZ AJ199 на **Rust + Tauri 2** и TypeScript/Vite.

## Что уже работает

- Чтение состояния: подключение, PID, прошивка, CID/MID, заряд, профиль.
- DPI: 8 ступеней, X/Y, цвет, активная ступень.
- Параметры: polling, debounce, LOD, angle snap, ripple.
- Кнопки: 12 слотов, известные действия, raw-коды и макросы.
- Подсветка: режим, скорость, яркость, цвет текущей ступени DPI.
- Макросы: имя, события key down/up, задержки, выбор клавиш по названию, добавление/удаление, импорт/экспорт `.jmm`, запись в мышь и назначение на кнопку.
- Меню **⋮**: разрешение записи, проверка записи, backup/экспорт/импорт, сброс профиля.
- Интерактивные контролы: сегментированные polling/LOD, pill-переключатели, карточки эффектов, пресеты цвета, «Сделать активной».
- Backup/экспорт/импорт JSON, сброс профиля.
- Трей, один экземпляр, тёмная тема, EN/RU, High-DPI.
- Закрытие/сворачивание окна уничтожает WebView2; окно создаётся заново из трея.
- Старт в трей (`--minimized`), автозапуск, лёгкий трей с DPI/зарядом и сменой ступени.
- Пауза UI-таймеров и CSS-анимаций при потере фокуса; `prefers-reduced-motion`.
- Тонкий индикатор режима чтения, disabled-стили с подсказками, «Информация об устройстве», понятные названия кнопок, исправленный счётчик ступеней DPI.
- Все записи создают backup и проверяются чтением обратно.
- При потере устройства открытие повторяется, GUI показывает офлайн и подсказку разбудить мышь.

## Ограничения

- Запись макроса требует разбуженной мыши: в покое EEPROM read может вернуть timeout; страница покажет подсказку.
- Полное соответствие LED-режимов (кроме Breathing = 2 и Off = 4) экспериментальное.
- Нет автозапуска и горячих клавиш.
- Профилей в OEM-интерфейсе фактически нет (только импорт/экспорт), поэтому панель профиля сведена к backup/export/import.

## Запуск

Требования: Node.js 20+, Rust 1.99+, WebView2 (на Windows 11 уже есть).

```powershell
cd apps\gui
npm install
npm run tauri dev
```

Сборка exe без установщика:

```powershell
npm run tauri build -- --debug --no-bundle
```

Готовый файл: `src-tauri\target\debug\aj199-gui.exe`.

**Важно:** не собирай exe через `cargo build` напрямую. Так Tauri делает dev-сборку, которая ищет Vite на `http://localhost:1420`, и при запуске без dev-сервера появляется `ERR_CONNECTION_REFUSED`. Используй `npm run tauri build` или `build.cmd`.

Для ленивых: двойной клик по `build.cmd` — он соберёт exe и скопирует его в `builds\aj199-gui-debug.exe` в корне проекта.

Полная сборка с установщиком:

```powershell
npm run tauri build
```
