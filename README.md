## Возможности

| | |
|---|---|
| **DPI** | До 6 ступеней, частота опроса до 1000 Гц, LOD и debounce |
| **Кнопки** | Схема мыши, переназначение действий, назначение макросов |
| **Макросы** | Запись с клавиатуры и мыши, задержки до 1000 мс, импорт и экспорт `.jmm` |
| **Подсветка** | Постоянная, дыхание, выключена |
| **Темы** | Deep, Sunset, Graphite, Phosphor, Fireflies, Aurora |
| **Трей** | Заряд на иконке и смена ступени DPI при закрытом окне |
| **Уведомления** | Низкий и критический заряд, полная зарядка |
| **Языки** | Русский и английский |

Настройки хранятся в памяти мыши и работают без запущенной программы. Каждая запись проверяется чтением обратно.

Проект не содержит прошивку и не умеет её обновлять.

## Установка

Скачайте файлы для своей системы со страницы [Releases](../../releases/latest). Устанавливать Rust и Node.js не нужно.

### Windows

Требуется Windows 10 или 11 x64.

1. Скачайте `aj199-control.exe`.
2. Запустите его.

Для работы нужен WebView2 Runtime. В Windows 11 он уже есть.

### Linux

Требуется x86_64 и glibc 2.35 или новее, например Ubuntu 22.04+ или Debian 12+.

> [!WARNING]
> Linux-сборка пока не проверена на настоящей мыши. Если что-то не работает, создайте issue.

1. Скачайте `aj199-control` и `99-aj199.rules`.
2. Установите библиотеки:

   ```bash
   sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0 libayatana-appindicator3-1 libnotify-bin
   ```

3. Разрешите доступ к мыши без root:

   ```bash
   sudo cp 99-aj199.rules /etc/udev/rules.d/
   sudo udevadm control --reload-rules && sudo udevadm trigger
   ```

4. Запустите программу:

   ```bash
   chmod +x aj199-control
   ./aj199-control
   ```

## Частые проблемы

**Настройки не записываются.** Мышь спит. Подвигайте её, запись включится сама.

**Программа закрылась, но работает.** Она свернулась в трей и продолжает показывать заряд. Выйти можно из меню иконки.

**На Linux мышь не определяется.** Проверьте, что установлено правило udev, и переподключите мышь или приёмник.

## Сборка из исходников

Нужны [Rust](https://rustup.rs) 1.99+ и [Node.js](https://nodejs.org) 24+.

На Linux сначала установите зависимости:

```bash
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev libudev-dev
```

Сборка:

```bash
cd apps/gui
npm install
npm run tauri build -- --no-bundle
```

Готовый файл появится в `apps/gui/src-tauri/target/release/`.

Запуск тестов:

```bash
cargo test --workspace
cd apps/gui/src-tauri && cargo test --lib
```

## CLI

`aj199ctl` работает с мышью из терминала. Запись требует флага `--allow-write`, перед ней автоматически создаётся резервная копия.

```bash
cargo run -p aj199-cli -- info
cargo run -p aj199-cli -- battery
cargo run -p aj199-cli -- dump-all --out backup.json
cargo run -p aj199-cli -- set dpi --stage 0 --x 800 --y 800 --allow-write
cargo run -p aj199-cli -- restore-backup backup.json --allow-write
```

Без мыши можно попробовать симулятор на записанном профиле:

```bash
cargo run -p aj199-cli -- --simulator dongle info
```

## Байты и функции

Контрольная сумма `chk` везде равна `0x55 - сумма защищаемых байтов` по модулю 256. Знак `?` отмечает значения, назначение которых не подтверждено.

<details>
<summary><b>Устройство</b></summary>

| Значение | Функция |
|---|---|
| VID `0x25A7` | производитель |
| PID `0xFA7B` | мышь по кабелю |
| PID `0xFA7C` | радиоприёмник 2.4 ГГц |
| usage page `0xFF02`, usage 2 | интерфейс команд |
| usage page `0xFF01`, usage 0 | интерфейс уведомлений |
| bcdDevice, например `0x1332` | версия прошивки, цифры двоично-десятичные: 13.32 |
| CID `0x40`, MID `0x01` | идентификаторы из ответа `CheckPsd` |

</details>

<details>
<summary><b>Кадры</b></summary>

| Байты | Функция |
|---|---|
| `08` | Feature Report: команда, 17 байт вместе с ID |
| `09` | Input Report: ответ, 17 байт вместе с ID |
| `08 <cmd> 00 <hi> <lo> <len> <data...> <chk>` | кадр чтения или записи EEPROM, данных до 10 байт |

</details>

<details>
<summary><b>Команды</b></summary>

| Команда | Функция | Ответ |
|---|---|---|
| `0x01` | `CheckPsd`: проверка устройства | `[10]` CID, `[11]` MID |
| `0x02` | `TellDrvStatus`: сообщить статус драйвера | подтверждение |
| `0x03` | `GetConnectStatus`: состояние связи, проба с checksum `0x00` | `[2]` статус |
| `0x04` | `GetPower`: заряд | `[6]` заряд 0–100, `[7]` зарядка |
| `0x07` | `WriteEEPROM`: запись | подтверждение |
| `0x08` | `ReadEEPROM`: чтение | данные с `[6]` |
| `0x09` | `ProfileReset`: сброс профиля к заводскому | подтверждение |
| `0x0E` | `GetCurProfile`: текущий профиль | 10 байт данных |
| `0x0F` | `GetStatus`: проба состояния ? | один байт-флаг |
| `0x10` | `SetCurProfile`: выбор профиля | подтверждение |

</details>

<details>
<summary><b>Профиль EEPROM `0x00..0xB7`</b></summary>

| Адрес | Формат | Функция |
|---|---|---|
| `0x00` | `[code, chk]` | частота опроса: `1` = 1000, `2` = 500, `4` = 250, `8` = 125 Гц |
| `0x02` | `[count, chk]` | число ступеней DPI |
| `0x04` | `[stage, chk]` | текущая ступень DPI, счёт с 0 |
| `0x06..0x09` | `00 55 00 55` | неизвестно ? |
| `0x0A` | `[value, chk]` | LOD |
| `0x0C..0x2B` | 8 × `[x_lo, y_lo, packed, chk]` | ступени DPI |
| `0x2C..0x4B` | 8 × `[R, G, B, chk]` | цвета ступеней DPI |
| `0x4C..0x53` | `[mode, chk, A, chk, B, chk, ...]` | основная подсветка |
| `0x54..0x5B` | 8 байт | подсветка логотипа ? |
| `0x5C..0x5F` | 4 байта | продолжение подсветки ? |
| `0x60..0x9F` | 16 × `[b0, b1, b2, chk]` | действия кнопок |
| `0xA0..0xA7` | 8 байт | параметры мыши ? |
| `0xA9` | `[value, chk]` | debounce, мс |
| `0xAB` | `[value, chk]` | неизвестно ? |
| `0xAD` | `[value, chk]` | сон ? |
| `0xAF` | `[value, chk]` | angle snap |
| `0xB1` | `[value, chk]` | ripple control |
| `0xB3`, `0xB5`, `0xB7` | `[value, chk]` | неизвестно ? |

</details>

<details>
<summary><b>DPI</b></summary>

| Байт | Функция |
|---|---|
| `x_lo` | младшие 8 бит `hw_x`, где `hw = DPI / 50 - 1` |
| `y_lo` | младшие 8 бит `hw_y` |
| `packed` | биты 2–3: старшие биты `hw_x`; биты 6–7: старшие биты `hw_y`; биты 0–1: множитель `mul` |
| `chk` | `0x55 - x_lo - y_lo - packed` |

Пример: 800 DPI, `hw = 0x00F`, байты `0F 0F 00 37`.

</details>

<details>
<summary><b>Подсветка, адрес `0x4C`</b></summary>

| mode | A | B | Функция |
|---|---|---|---|
| `0` | — | — | выключена |
| `1` | яркость: уровень × 25, уровень 10 = `0xFF` | `3` | постоянная |
| `2` | `0xFF` | скорость 1–5 | дыхание |

</details>

<details>
<summary><b>Действия кнопок</b></summary>

| Байты `b0 b1 b2` | Функция |
|---|---|
| `01 01 00` | левая кнопка |
| `01 02 00` | правая кнопка |
| `01 04 00` | средняя кнопка |
| `01 10 00` | вперёд |
| `01 08 00` | назад |
| `02 02 00` | DPI + |
| `02 03 00` | DPI − |
| `02 01 00` | цикл DPI |
| `00 00 00` | кнопка отключена |
| `06 <id> <flag>` | макрос `id`; смысл `flag` неизвестен, встречаются `01` и `FE` ? |

Номер кнопки на схеме и слот в таблице `?`: 1 → 0, 2 → 1, 3 → 2, 4 → 4, 5 → 3, 6 → 5.

</details>

<details>
<summary><b>Макросы</b></summary>

Слот макроса начинается с адреса `0x300 + index × 0x180`, слотов 16. Стёртый слот заполнен `0xFF`.

| Смещение | Формат | Функция |
|---|---|---|
| `0x00` | 1 байт | длина имени в байтах |
| `0x01..0x1E` | UTF-16 | имя, до 30 байт |
| `0x1F` | 1 байт | число событий |
| `0x20` | N × `[flags, hid, 00, delay_hi, delay_lo]` | события |
| после событий | `[chk, 00, 00, 00]` | `chk = 0x55 - сумма(count..events)` |

| Поле | Значение | Функция |
|---|---|---|
| `flags` | `((state & 1) + 1) × 0x40 \| kind` | состояние и тип события |
| `kind` | `0` | модификатор Ctrl, Shift, Alt, Win: маска в поле `hid` |
| `kind` | `1` | клавиша HID |
| `kind` | `4` | кнопка мыши: маска в поле `hid` |
| `kind` | `5` | колесо |
| `delay` | мс, big-endian | пауза выполняется **после** события |

</details>
