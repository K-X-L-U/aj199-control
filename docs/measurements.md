# Замеры памяти и запуска

Windows 10/11 x64, debug-сборка Tauri (`--debug --no-bundle`), приёмник `0xFA7C`.
Память — сумма WorkingSet процесса `aj199-gui-debug.exe` и всех дочерних
`msedgewebview2.exe`. Замеры приблизительные, но одинаковые по методике.

## Этап 1: до и после

| Состояние | До (скрытие окна) | После (уничтожение окна) |
|---|---:|---:|
| Окно открыто, всего | 364.1 МБ | 378.5–390.1 МБ |
| Окно открыто, WebView2 | 334.0 МБ / 6 процессов | 348.3–359.3 МБ / 6 процессов |
| В трее, всего | 385.3 МБ | **30.6–31.1 МБ** |
| В трее, WebView2 | 355.2 МБ / 6 процессов | **0 МБ / 0 процессов** |
| Процесс после закрытия | жив | жив |
| Главное окно после закрытия | скрыто | уничтожено |
| Старт в трее (`--minimized`) | — | 17.7 МБ, 0 WebView2 |
| Сворачивание в трей | окно скрыто | окно уничтожено, ~32.6 МБ, 0 WebView2 |
| Release, окно открыто | — | 370.4 МБ, 6 WebView2 |
| Release, в трее | — | **24.6 МБ, 0 WebView2** |

### Холодный старт

- Debug после этапа 1: **378–734 мс** до появления окна `AJAZZ AJ199` (разброс из-за холодного WebView2).
- Release после этапа 1: **357 мс**.
- До этапа 1 замер дал 96 мс, но тогда скрипт ловил первое окно с непустым
  заголовком и мог попасть на скрытое окно single-instance `com.aj199.control-siw`.
  Поэтому 96 мс не считается корректным baseline для главного окна.

### Что проверено вручную

- Закрытие главного окна через `WM_CLOSE`: окно исчезает, все дочерние
  `msedgewebview2.exe` завершаются, Rust-процесс остаётся в трее.
- Повторный запуск exe: single-instance не создаёт второй процесс, а
  пересоздаёт главное окно в первом процессе.
- `--minimized`: процесс стартует без окна и без WebView2.
- Сворачивание главного окна: WebView2 уничтожается, процесс остаётся в трее.
- Закрытие/сворачивание не завершает приложение; выход — только через трей.

## Как повторить

Скрипт замера лежит вне репозитория (временный `measure_aj1992.ps1`). Методика:

1. Запустить exe, дождаться окна `AJAZZ AJ199`.
2. Суммировать WorkingSet процесса и всех потомков через `Win32_Process`.
3. Отдельно суммировать `msedgewebview2.exe`.
4. Отправить `WM_CLOSE` главному окну, подождать 20 с (WebView2 завершается не мгновенно),
   повторить замер.
5. Проверить, что процесс жив, окно `AJAZZ AJ199` отсутствует, а WebView2 — 0.
